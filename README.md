# EduMate AI

EduMate AI is a personalized learning platform that adapts content based on student learning styles like visual, reading, and interactive formats. It enhances productivity using AI-powered tools.

## 🚀 Features

* AI-based personalized learning
* Virtual study rooms
* Pomodoro timer
* Task management
* AI assistant
* Progress tracking

## 🛠️ Tech Stack

* Frontend: React / Next.js
* Backend: Node.js / Python
* Database: Firebase / MongoDB
